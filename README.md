## 🧠 Aprendizajes del día

- `print()` = mostrar cosas en pantalla
- **Variables** = cajas donde guardo datos (`nombre = "Richard"`)
- `input()` = mi programa pregunta y espera mi respuesta
- `float()` e `int()` = convertir texto en números
- `if / else` = mi programa DECIDE
- `round()` = redondear decimales

## 💥 Errores picantes del día

- **SyntaxError**: puse un espacio dentro del nombre de una variable (`presupuesto diario`) → correcto: `presupuesto_diario`
- **IndentationError**: me faltó el Tab (sangría) después del `if` → en Python **la sangría ES gramática**
